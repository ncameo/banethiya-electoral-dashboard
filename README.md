# Banethiya Electoral Dashboard

Aggregate ward-level dashboard for Gram Panchayat Banethiya.

This repository is designed for aggregate electoral-roll and public-development analysis. It does not include individual voter names, EPIC numbers, addresses, or political preference profiling.

## Scope
- 9-ward aggregate summaries
- Polling-station/locality summaries when source data is available
- Male/female aggregate counts
- Development/issues tracker
- Source and data-quality notes
